# 浏览器获取流程

从语雀网页迁移时阅读本参考。默认使用 Codex 内置浏览器，不要求用户预先在外部浏览器登录。

## 明确迁移范围

从用户请求和可见界面中明确以下信息，只询问缺失的关键选择：

- 源文档链接，或语雀知识库中明确选中的文档；
- 迁移范围是一篇文档、一个目录，还是整个知识库；
- Obsidian 笔记库和目标目录，或具体笔记文件名；
- 同名笔记已存在时的覆盖授权。

展示简洁映射，例如 `https://www.yuque.com/.../doc -> 项目/语雀/设计.md`。不得根据当前工作目录猜测笔记库，也不得从单篇页面链接推断要迁移整批文档。

## 内置浏览器入口与登录

1. 默认选择 Codex 内置浏览器（`iab`），只复用其中的语雀标签页或打开用户指定的链接。不得因为某个外部浏览器已登录而默认改用它；用户明确指定其他浏览器时才切换。
2. 使用浏览器控制工具返回的当前状态确认是否有可复用标签页。已有内置标签页时用已知标签页引用获取；没有时可使用支持的入口 `await cua.createBrowserTab("iab", SOURCE_URL, { visible: true });`。SOURCE_URL 替换为用户提供的语雀链接；具体调用以当前工具文档为准。首次调用只执行工具要求的一个入口，读取返回文档后再导航或操作页面。
3. 检查页面是否显示登录、验证码或权限限制。需要登录时让用户在这个可见的内置标签页手动完成，不索取密码；用户确认后重新读取页面，确认进入授权文档或知识库再继续。外部浏览器登录不等于内置浏览器已登录。
4. 内置工具连接与语雀登录是两个独立前提。工具不可用时报告限制，请用户提供本地导出或明确选择另一浏览器；不默认安装扩展，不读取浏览器配置、Cookie、令牌或私有存储。

## 会话与导出

复用内置浏览器中的登录会话，在用户提供的源链接范围内操作。登录失效或出现验证码、权限障碍时暂停获取，请用户在当前内置标签页接管；无法恢复时请求本地导出。不得绕过访问控制。

单篇优先使用可见的 Markdown 导出入口；整库优先使用原生 .lakebook 导出，不选择 PDF 作为可编辑笔记源。下载文件作为临时输入处理。文件保存于可写工作区之外时，只读取该次迁移所需文件即可，不移动或删除其他下载文件。不上传 Obsidian 笔记库，也不将笔记内容粘贴到第三方转换网站。

## 整库 .lakebook 获取：已验证的界面路线

1. 在内置浏览器打开用户指定的仪表盘知识库列表，在可见界面定位指定知识库。进入后核对库名、文档数及标题清单，不把库名误当成单篇文件名。
2. 在知识库左上角的“···”菜单选择“更多设置”，再进入页面中的“更多设置”。
3. 找到“导出知识库”，选择“语雀知识库 .lakebook”，等待生成完成后点击下载。菜单名称可能变化，以当时可见界面为准，不猜测内部导出接口。
4. 通过浏览器工具的下载结果确认实际文件路径。无需读取 Cookie 或复制登录令牌；下载的是指定范围的语雀原生导出。
5. 用 tar/JSON 检查导出文档清单是否与界面一致；.lakebook 不是 ZIP。整库导出可能包含空白未发布草稿，应列出并核对，不能以其无正文判定导出失败。

本路线已验证普通 lake 文档的标题、列表及空白草稿。复杂表格、公式、嵌入卡片和附件仍须逐项验收，不能由简单样例推断所有格式均完整。只请求部分文档时使用暂存器的 `--slug` 筛选；若导出整库本身会扩大用户授权的读取范围，改用单篇导出或先询问。

没有导出入口但获授权的文档正文可读时，通过已说明的浏览器 API 或无障碍信息提取渲染后的正文。不得只凭截图还原代码或长文本，不猜测隐藏 API 地址，不读取浏览器存储。排除菜单、导航、评论和无关文档。必要时滚动加载完整正文，保留标题、列表、代码语言和空白、表格、公式、链接及附件 URL，再通过常规文件工具保存为 Markdown 或 HTML。将正文首尾和关键内容块与可见原文核对。无法确认完整性时，明确说明仅获取了部分内容并请求原生导出，不将其作为完整迁移交付。

仅通过支持的浏览器下载操作，将指定文档的远程附件保存到本地。资源依赖 Cookie 或无法下载时，保留原链接并说明离线查看尚不完整。不得将 Cookie 导出给下载工具，也不得把私有文档内容转发到其他服务。

## 交给转换器

成功下载或完整提取正文后：

1. 确认取得的 Markdown、HTML、ZIP 或 .lakebook 文件。后者先运行 `scripts/lakebook_to_markdown.py BOOK.lakebook EMPTY_STAGING_DIR`，将指定文档暂存到笔记库之外；其他格式及附件按迁移参考处理。
2. 单篇笔记的指定文件名使用 `--output-name NAME`；目录或批量迁移使用 `--root-folder FOLDER`，保留相对源路径。
3. 执行预演并展示计划。在已授权目标下新建笔记时使用 `--apply`；遇到覆盖冲突先确认。经核实的导出附件位于文档父目录之外时，使用 `--asset-root` 指定范围。
4. 如实报告远程图片、缺失附件、未解析文档链接和冲突，不静默丢弃问题。逐篇检查正文首尾、关键段落和空白草稿；若仅完成磁盘文件核验，不能声称已经在 Obsidian 应用中打开检查。
